# BridgeNH 工具能力索引

[English](capabilities.md) | [简体中文](capabilities_zh.md)

供人工阅读和审核；Agent 使用英文入口，完整规则见[启动模板](workspace_zh.md#可复制的启动提示词)。

通过 `mcb_help({"topic":"capabilities"})` 可离线读取英文索引；本索引覆盖当前版本的全部公开工具，包括四个前端管理工具。工具存在不代表所有客户端、服务器、模组版本或权限均支持执行。

## 功能检索与源码查阅

1. 从下面的分类选工具。绑定和策略见[总览](overview_zh.md)，机器和库存流程见[操作](operations_zh.md)，另有 [NEI](nei_zh.md)、[AE2](ae_zh.md)、[测试](testing_zh.md)和[维护](maintenance_zh.md)指南。
2. 用名称片段查询已加载目录：`mcb_help({"topic":"tools","query":"bookmark","limit":20})`。匹配的是工具名，不是自然语言描述。准确参数和完整说明使用 `mcb_help({"topic":"tools","tool":"mcb_nei_bookmark_action"})`。
3. 翻页使用返回的 `nextOffset`，并把 `catalogFingerprint` 传为 `expectedCatalogFingerprint`。列表摘要可能截断，单工具查询返回完整 schema；重载后重新查询。
4. `mcb_backend_status`、`mcb_backend_restart`、`mcb_clients`、`mcb_connection` 属于前端，使用宿主提供的直接调用 schema，不在 worker 的 `topic="tools"` 目录中。因此查询这些管理工具返回 `UNKNOWN_TOOL`，不等于它们不存在。
5. 游戏操作还须核对当前对话绑定和 `mcb_health` 的实际能力/策略、当前身份与 coverage。宿主仍缓存旧工具目录时，按[维护指南](maintenance_zh.md#发现与调用当前工具)使用受保护的兼容调用。只有指南、实时 schema 和原生观察仍无法回答具体问题时，才查对应版本源码。

只读不等于无需运行中的客户端、服务器桥接或观察权限。控制操作通常会建立后台保护，读取保持玩家的控制选择；未知效果先核对，不重放。

## 连接、帮助与维护

| 工具 | 用途与验收边界 |
| --- | --- |
| `mcb_help` | 读取固定离线指南、当前 worker 目录和准确 schema。功能选择看本索引，当前参数看 `topic="tools"`。 |
| `mcb_clients` | 列出指定 Prism 目录内的实例，不绑定、不启动；runtime 文件存在不代表在线。 |
| `mcb_connection` | 查询、明确绑定或解绑当前对话。使用实际对话 ID、当前代数和新请求 ID；新前端不默认绑定。 |
| `mcb_backend_status` | 查看前端/worker、代数、指纹和目录通知观察，不调用游戏、不重启。 |
| `mcb_backend_restart` | 在同一 MCP 连接中替换兼容 worker 代码、工具/资源和指南；核对状态交接及宿主实际刷新，详见[维护](maintenance_zh.md)。 |
| `mcb_health` | 读取实际实例/会话、就绪状态、执行版本、权限和能力；当前就绪不证明后续加载或动作完成。 |
| `mcb_policy` | 读取或保存存档/服务器的操作意图；生存、高效、创造、完全支配及移动/QA 上限仍受实际权限约束，不授予 OP 或飞行。 |

## 客户端生命周期与原生窗口

| 工具 | 用途与验收边界 |
| --- | --- |
| `mcb_launch` | 对所选实例启动一次；`windowMode=minimized` 默认最小化至任务栏，另可选 `background`（显示但不激活）、`normal`，要求客户端窗口控制 v2。`action="status"` 只读续查。Java 进程存在不等于就绪，未知启动不得重发。 |
| `mcb_worlds` | 列出已有存档及准确文件夹名，不创建、删除或载入世界。 |
| `mcb_load_world` | 在主菜单按当前会话载入获准的已有存档；等待实际 world readiness。 |
| `mcb_connect_server` | 通过正常连接流程连接明确的 host 和独立 port，使用启动器认证；核对实际连接与世界，而非仅看调度回执。 |
| `mcb_leave_world` | 正常保存并离开拥有的单人/LAN 世界，或断开服务器；使用当前会话及 `health.lifecycleTarget.expectedWorld`，核对回到菜单。 |
| `mcb_exit` | 正常保存/断开并关闭所选客户端；核对进程退出，scheduled 不代表关闭完成。 |
| `mcb_window` | 读取实际窗口模式、原生标志、客户端/帧缓冲大小和动作支持；全屏偏好与实际全屏状态分开。 |
| `mcb_window_action` | 最大化、还原、最小化、调整尺寸，或明确切回窗口模式。Windows 操作保留焦点和层级。resize 要求 width/height；绑定当前会话/窗口/模式，核对 confirmed 和后续尺寸，不保存窗口偏好。 |

重连后的首次启动中，关闭的客户端还不能通过在线绑定验证。应先使用用户明确选定实例的受支持启动器入口，待就绪后绑定，详见[维护](maintenance_zh.md#客户端启动与绑定)。

| --- | --- |

| `mcb_gui_widget_action` | 激活或编辑已声明的原生控件，支持的假物品动作使用实际适配语义；核对同步值和假光标清理。 |
| `mcb_gui_tooltip` | 不移动实体鼠标，读取真实槽位或当前缩放坐标提示；真实堆叠/NBT/流体数据优先于注册表模板。 |
| `mcb_gui_pointer` | 设置/清除短期、绑定界面的逻辑悬停，不移动系统鼠标；完成原生帧后才判定悬停文本有效。 |

| `mcb_open_inventory` | 从世界视图打开正常玩家背包；支持的创造客户端会选玩家背包页以正常同步，核对实际 GUI/槽位。 |
| `mcb_open_pause_menu` | 在世界视图、空光标时打开原生游戏菜单；读取当前控件，暂停可能停止内置服务器进度。 |
| `mcb_close_gui` | 提交一次正常关闭；后续低层移动/投料前，核对更新的服务端/客户端容器状态，不把提交当关闭确认。 |

| --- | --- |
| `mcb_machine_inspect` | 读取当前机器状态/部件及支持的远程权威观察；缓存配方或显示进度不证明当前生产。 |

| `mcb_recipe_once` | 用真实控制完成支持的定量配方及消耗、产物、回收、停机验证；真实库存选不生成/保留，明确创造准备可能清空并补给。 |

## 可选 QA

这些工具需要已声明的 QA 集成和实际策略/权限，不是普通 BridgeNH 的前置。阅读[测试](testing_zh.md)指南；不因工具存在就安装 QA、提高策略或使用生产区域。

| 工具 | 用途与验收边界 |
| --- | --- |
| `mcb_qa_catalog` | 发现支持的用例、公开测试布局、诊断和同次运行证据；缺 QA/API 明确不可用，原型不是已成立机器。 |
| `mcb_qa_run` | 提交一次获准用例或受支持的不可变声明组；绑定真实 runner/世界/维度和返回 runId，提交不代表 PASS。 |
| `mcb_qa_status` | 读取准确运行的状态及可用有界等待；无限运行的 observation-ready 产出不证明有限完成或稳定停止。 |
| `mcb_qa_results` | 分页读取同次运行用例/问题和可选详情；保留 run 身份、归属和 coverage，旧全局结果不作当前验收。 |
| `mcb_qa_cancel` | 请求支持的所属运行正常停止并排空；对同一 run 验证回收和停机，不全局取消或强行停止未支持流程。 |
| `mcb_qa_command` | 只在准确范围调用已有公开 QA 命令；清测试结构与忘记记录不同，保留归属，不作任意命令执行。 |
| `mcb_qa_test_once` | 一次完成支持的有限测试所需发现、预检、提交、等待、结果和后查；需要时要求全流程证据，不重复内部检查。 |

## 诊断、消息、日志与知识

| 工具 | 用途与验收边界 |
| --- | --- |
| `mcb_diagnostics` | 读取有界 JVM/堆/FPS/服务器执行耗时，或支持的离线固定实例进程诊断；耗时不是 TPS，进程不代表世界就绪。 |
| `mcb_logs` | 读取所选客户端固定游戏日志的有界尾部；历史报错和不完整日志不证明当前状态或未执行。 |
| `mcb_mods` | 读取实际活动模组版本与加载来源，必要时加执行证据；磁盘候选或当前文件哈希不能单独证明已加载字节。 |
| `mcb_messages` | 按返回序号读取有界游戏聊天/系统消息，不发送、不读任意文件。 |
| `mcb_chat` | 在游戏长度限制内发送获准的原生命令或聊天，仍受服务端权限限制；提交后核对反馈与效果。 |
| `mcb_dialogue` | 启停/查询获准的玩家到对话转发，或回复准确消息引用；玩家文本仍是具名输入而非系统权限，未知投递不重放。 |
| `mcb_recording` | 用 summary/list/events 或 live 读取被动玩家记录；磁盘历史可离线读取，缺口和缺停止标记仍未知，不回放。 |
| `mcb_run_log` | 读写所选实例的 Agent 日志配置和问题报告、解决、延期、导出；历史和总结不证明游戏效果。 |
| `mcb_knowledge` | 按真实证据和兼容上下文查询、复核、记录本地经验；区分推测与验证结论。 |

选择能负责目标效果及验收的最小已有工作流。保留完整身份、十进制数量、当前会话/世界/维度与归属。自动清理已确认仅本任务使用的 NEI 假物品/书签，保留待用项、真物品和已保存目标配置；交回人工控制前停止所属输入任务。
